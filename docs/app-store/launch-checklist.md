# StarPort App Store launch checklist

## Prepared
- [x] App record and signed TestFlight version 0.2.0 (100003)
- [x] First original illustrated adventure; five permanent endings, twelve rewindable detours
- [x] App icon included in signed archive (iPhone/iPad icons and `CFBundlePrimaryIcon`)
- [x] English store description, subtitle, promotional text, keywords and reviewer notes
- [x] Public support page and privacy policy draft

## Required before public release
- [ ] Confirm Apple build processing and whether the app icon displays in TestFlight and App Store Connect
- [ ] Apply/review en-US metadata in App Store Connect; use the same approved wording
- [ ] Select Games → Adventure category, complete content-rights declaration
- [ ] Answer the App Store age-rating questionnaire accurately; choose **Override to Higher Age Rating: 13+**
- [ ] Review Google SDK disclosures and complete App Privacy answers and privacy policy URL
- [ ] Capture **real screenshots** on iPhone and iPad: library/cover, illustrated story, decision screen, false-ending rewind, achievements, appearance settings
- [ ] Verify support email and required App Review contact name and phone
- [ ] Configure and approve the Remove Ads product and IAP review screenshot, or hide unfinished purchase copy before submitting
- [ ] Configure production AdMob IDs and teen-safe consent setup before enabling ads in a later release
- [ ] Confirm territory availability/pricing and attach the release build to the intended version
- [ ] Submit for App Review only after the above is complete

**Screenshot sequence:** 1. Adventure library; 2. A warning from tomorrow; 3. Decisions and stats; 4. Wrong turn and rewind; 5. Achievements; 6. Dark/light settings.

No public App Store submission should be triggered by metadata synchronization.
